# Menna Khaled Gamal – Portfolio

React + TypeScript + Tailwind (Vite). Content is in `src/data/content.ts`.

## Run
    npm install
    npm run dev

## Replace
- Photo: `public/assets/profile.jpg` (about 800x1000px, under 200 KB)
- CV: `public/assets/Menna-Khaled-CV.pdf`
- Projects: edit `projects` in `src/data/content.ts`

## Deploy to Vercel
Import the repo in Vercel (Vite is auto-detected), or run `npx vercel`. Optional env vars: see `.env.example`.
